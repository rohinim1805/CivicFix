# CivicFix — Smart Community Issue Reporting Prototype

CivicFix is a front-end prototype for a social-impact hackathon. It helps residents report community issues and track their status.

## Features
- Submit a report with title, category, priority, location and description
- Search reports by title, location or category
- Filter reports by status
- Update a report through Submitted, In Progress and Resolved
- Dashboard counts for total, unresolved and resolved reports
- Responsive layout for mobile and desktop
- Demo data to make the prototype easy to demonstrate

## Run the project
1. Download and extract `CivicFix.zip`.
2. Open the extracted `CivicFix` folder.
3. Open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
4. Try submitting a report and changing its status.

No installation or API key is required.

## Important prototype limitations
- Data is stored in the current browser using localStorage. It is not shared between devices or users.
- No real government department is connected.
- The optional photo is not uploaded or stored.
- This is a demonstration prototype, not a production reporting service.
